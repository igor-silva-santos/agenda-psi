## ✨ Destaques

- 📅 **Agendamento completo** — disponibilidade configurável, bloqueio de horários, sincronização com Google Calendar.
- 💳 **Faturamento** — geração de faturas por consulta, controle de status e PDF para download, tanto no admin quanto no portal do paciente.
- 📊 **Relatórios** — visão mensal e anual de produtividade e faturamento, com gráficos.
- ✍️ **Assinatura digital de documentos** — link único, assinatura por canvas e validação de CPF, sem depender de serviços de terceiros.
- 🔔 **Notificações + Auditoria** — sino de notificações e histórico auditável de ações administrativas.
- ✅ **Validação Rigorosa** — uso de Zod para garantir dados 100% corretos.
- 🛡️ **Type-Safe** — TypeScript estrito de ponta a ponta.

## 💡 Por que este projeto?

O objetivo foi resolver uma dor real de profissionais de saúde: gerenciar agenda, cobrança e documentação de pacientes em um só lugar. É a versão pública e simplificada de um sistema que rodou (e cresceu) em produção para uma clínica real — os dados e integrações específicas do negócio foram removidos, mas a arquitetura e as funcionalidades centrais foram mantidas.

## 🛠️ Tecnologias

- **Next.js / React** — framework e componentes.
- **Prisma + Supabase (PostgreSQL)** — schema versionado, consultas via cliente Supabase.
- **Zod / React Hook Form** — ecossistema de validação e formulários.
- **@react-pdf/renderer** — geração de PDFs de fatura.
- **Recharts** — gráficos dos relatórios.
- **Tailwind CSS** — estilização moderna e rápida.
- **Date-fns** — tratamento complexo de datas.

## 🚀 Roadmap (onde este projeto pode chegar)

- [ ] **WhatsApp Reminders:** envio automático de lembretes para evitar faltas.
- [ ] **Telemedicina:** integração com vídeo-chamada nativa.
- [ ] **Multi-profissional:** mais de um profissional na mesma conta, com agendas independentes.
